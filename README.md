# 3. Vercel Deployment

The GitHub repository is connected with Vercel for automatic deployment.

## Deployment Flow

```
Code Changes
      |
      v
GitHub Push
      |
      v
Vercel Build Process
      |
      v
Live Portfolio Website
```

Whenever changes are pushed to GitHub:

1. Vercel detects the latest update.
2. A new production build starts automatically.
3. The latest version is deployed to the live website.

## Step 2: Make Required Changes

* Update skills
* Modify experience details

* Update images

## Step 3: Test Locally

Run the development server:

```bash
npm run dev
```

Check:

* Website loading
* Images
* Navigation links
* Mobile responsiveness
* Contact form functionality

---

```bash
git add .
```

```bash

```


## Step 5: Verify Vercel Deployment

# Troubleshooting

## Vercel Deployment Failed

Check:

* Vercel build logs
* Package dependencies
* Environment variables
* Node.js version compatibility

---

## Website Not Updating

Check:

* Latest GitHub commit exists
* Vercel deployment completed successfully
* Browser cache
